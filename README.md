# M I R A — Site Vitrine

Site web vitrine pour mira-app, une application de gestion de logements adaptée aux réalités congolaises.

## Démarrage rapide

### Prérequis
- Node.js 18+ 
- npm ou yarn

### Installation

```bash
# Installer les dépendances
npm install

# Lancer en mode développement
npm run dev

# Build de production
npm run build
npm start
```
